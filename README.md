# Diwali Sales Data Analysis

## Overview
This project explores Diwali sales data to identify customer purchasing
patterns and understand which customer groups and product categories
generate the most orders.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Objectives
- Clean and prepare the sales dataset.
- Analyse customer demographics and purchasing behaviour.
- Identify popular product categories.
- Explore sales and order patterns across different states.
- Visualise findings using charts and graphs.

## Key Findings
- Analysed purchasing patterns across different age groups and genders.
- Identified states with the highest total number of orders.
- Examined the products with the highest recorded order totals.
- Explored purchasing patterns across marital status, occupation
  and product categories.

## Conclusion
The analysis suggests that married women aged 26–35 from Uttar Pradesh,
Maharashtra and Karnataka, working in IT, Healthcare and Aviation,
are more likely to purchase products from the Food, Clothing and
Electronics categories.

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the notebook cells to reproduce the analysis.
